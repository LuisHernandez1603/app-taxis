FLUJO DE NAVEGACION:
====================

1. Usuario accede → index.html (LANDING PAGE PUBLICA)
   - Información de servicios
   - Botón "Inicia Sesión" → login.html
   - Botón "Reservar Viaje" → login.html
   - Botón "Soy Conductor" → login.html

2. Usuario hace click en Login → login.html (LOGIN)
   - Ingresa credenciales O selecciona usuario demo
   - AUTH.login() valida credenciales
   - Si es válido, guarda en localStorage
   - Redirige a su dashboard según rol

3. SEGUN EL ROL:
   ✓ ADMIN → admin-dashboard.html (Dashboard de administración)
   ✓ DRIVER → driver-panel.html (Panel del conductor)
   ✓ PASSENGER → passenger-panel.html (Panel del pasajero)

4. Si intenta acceder directamente a una ruta protegida sin autenticación
   → Redirige a login.html

5. Si intenta acceder a ruta de otro rol
   → Redirige a su dashboard correcto

COMO FUNCIONA LA AUTENTICACION:
================================

1. Usuario ingresa email/password en login.html

2. Se llama AUTH.login(email, password) en js/auth.js

3. Si es válido:
   - Guarda en localStorage: {email, role, name, loginTime}
   - Retorna {success: true}
   - Redirige a index.html

4. En cada página protegida se ejecuta:
   - AUTH.redirectByRole() → Verifica si está autenticado
   - Si no tiene sesión → Redirige a login.html
   - Si tiene sesión pero rol no permite → Redirige a su dashboard
   - Si todo OK → Muestra la página
   - AUTH.initUI() → Actualiza header con nombre del usuario

5. Para logout:
   - Click en botón de logout
   - AUTH.logout() → Limpia localStorage
   - Redirige a index.html
